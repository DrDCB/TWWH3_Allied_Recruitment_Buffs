# Allied Recruitment Buffs
A mod for Total War Warhammer III. It seems there are a few mods that tweak this already, but here's another.
* Sets the cap for allied units and Ogre mercenaries to 19 per army
* Boosts Allegiance points gain per turn to a user-defined amount (default 50 pts)
* Raises the Allegiance point cap to 99999
The outpost tier cost scaling remains the same (tier 2/3 halves the cost).

Note that in order to set a custom points gain value, you'll need to subscribe to MCT. However, it is not a hard requirement. The mod will use a default of 24x (50 points a turn) if you don't use MCT. Changing the value in MCT mid-campaign will apply the next time you load a save. Note that this is the base value, so additional multipliers from other sources will stack. Because of the way the multiplier is applied, it only affects the player, not the AI (unlike table edits).
